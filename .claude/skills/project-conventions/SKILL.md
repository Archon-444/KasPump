# KasPump conventions: current vs legacy

The V2 rework (May 2026) left two generations of patterns in the tree. This skill says which is which. For commands and architecture, see CLAUDE.md.

## Bonding curve: sigmoid only

**Current**: every token uses the fixed sigmoid curve in `contracts/libraries/BondingCurveMath.sol` (31-anchor piecewise-linear table). `BondingCurveAMM.curveType()` hard-returns `2` (SIGMOID); per-token `basePrice`/`slope`/`curveType` constructor params were removed in V2. Frontend code should report `curveType: 'sigmoid'` — see `src/hooks/useContracts.ts`, `src/services/token.service.ts` for the current pattern.

**Legacy — do not extend into new code**: `'linear' | 'exponential'` unions and `basePrice`/`slope` fields survive only for indexer/backfill compatibility in:
- `src/hooks/useTokenQuery.ts`
- `src/hooks/useSubgraphTokens.ts`
- `src/schemas/index.ts` (`CurveTypeSchema` and the old launch-form validators)
- `src/types/index.ts` (`BondingCurveConfig`, `CURVE_TYPES`)

New features must not accept, validate, or display a curve choice.

## Launch flow

**Current**: `src/components/features/QuickLaunchForm.tsx` (name/ticker/image only, "30-second launch"), used by `src/app/launch/page.tsx` and `src/app/creator/page.tsx`.

**Legacy**: `src/components/features/LaunchPad.tsx` — the old 5-step wizard with curve configuration. It is orphaned (no page imports it) and is also the single worst type-rot file. Never use it as a reference. `tools/token-launch-wizard/` is likewise legacy.

## Dead and generated files

- `src/hooks/useWallet.ts.old` — dead, ignore.
- `typechain-types/` — generated by `npm run compile`; never hand-edit.
- `src/abis/*.json` and `server/src/abis/*.json` — hand-synced copies of contract ABIs; update them after contract changes (they are NOT auto-generated).

## Stale documentation

- `AGENTS.md` predates V2 where it describes curves ("linear, exponential, adaptive") and references `tools/token-launch-wizard/` — CLAUDE.md and this skill win on conflicts.
- `TECHNICAL_DEBT.md` is pre-V2 (still useful for holder-count/metrics placeholders).
- `docs/archive/` and root `archive/` are historical records, not current guidance.

## Type errors

~5,100 pre-existing `error TS` lines, concentrated in page/component files (worst: `LaunchPad.tsx`, `TokenCard.tsx`, `MobileTokenCard.tsx`, `MultichainWalletButton.tsx`, `AdminDeploymentDashboard.tsx`, static pages). Treat these files' patterns as anti-examples. Don't add new errors: run `npx tsc --noEmit --ignoreDeprecations 6.0` and compare the error count against baseline rather than expecting zero. The `/type-debt` skill exists to burn this down.
